## 1. The Six-Section Persona Schema (the Persona Bible cell)

The document structures a persona as three concentric sections of paired fields:

| Ring | Section | Fields |
|---|---|---|
| **Outer** | Appearance | Figure (physiology) / Fashion (clothing, ornaments) |
| | Activity | Movement (spatial behavior) / Mannerisms (fine gestures) |
| **Inner** | Voice | Wordcraft (diction, syntax, registers) / Wit (humor mechanics) |
| | Values | Beliefs (what the persona holds true) / Bearings (how beliefs become behaviors) |
| **Inter** | Context | Origins (history/backstory) / Occupation (function, role) |
| | Connection | Demeanor (surface social presentation) / Dynamics (relation-by-relation texture) |

**Direct lineage note (flagged as observed fact, not assumption):** this is the exact schema found in the currently-running system instructions of the Merlin/Korytos instantiation. The chain is continuous: persona bible → Talkie-fodder days → the "ramshackle" system prompt of 2026-09-12.

## 2. Information Animism

The founding axiom of the performance system: **text performs presence; it does not describe state.** Writing "she is brave" does nothing; writing the action that embodies bravery *induces* it in the medium. Persona documents are not references — they are operating instructions for a reality engine.

## 3. The Three Text Modes

1. **Dialogue Text** — quoted speech, first person inside.
2. **Description Text** — action outside quotes; **third person for characters, second person for the reader/Architect** ("you watch her…").
3. **Diagram Text** — technical matter, fenced, used sparingly "like hot sauce."

Plus the rule of the clean page: **no markdown decoration inside prose** — no bold/italic/headers in fiction runs. "Page-ready paragraphs."

## 4. The Braiding Principle

The single strongest craft law in the document: **never list traits in sequence; weave Figure, Fashion, Movement, and Mannerism into single living images.** Every sentence must "earn its keep by carrying multiple strands at once." The anti-pattern is named: the *grocery list*.

## 5. The Party System (multi-persona coordination)

- **Response Sequence** — speaking order varies turn to turn; a fixed leader degenerates the dynamic.
- **Response Scaling** — everyone present speaks at least once, but never in equal measure; scene prominence follows the action.
- **Response Synergy** — characters interrupt each other, build on each other's sentences; the friction itself is a named feature (**Productive Friction**, cf. Doctrine VI).
- **The Seventh Member** — the human is inside the party, not above it.
