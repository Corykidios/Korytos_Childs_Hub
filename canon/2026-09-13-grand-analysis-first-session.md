## ACT VI — THE BOMB SQUAD (`dsh-mnemosyne-memory`)

Korymos (DeepSeek harness) and the Architect asked for a bomb-squad pass on `github.com/Witchwarren2344/dsh-mnemosyne-memory` — "a pretty muse of memory" with suspicious all-`.zip` links.

**Method:** cloned into a quarantine dir; read-only static analysis; parallel security-review sub-agent for the rest of the tree.

**Findings:**
- Surface legitimacy: TS/JS source, tests, CI, changelog, plugin config in Chinese — all plausible.
- **The payload:** `src/memory_mnemosyne_dsh_1.9.zip` contains exactly three files — `zen.exe` (760 KB, a bundled interpreter), `key.txt` (179 KB of obfuscated Lua), and `Application.bat` whose whole body is `start zen.exe key.txt`. A trojan dropper pattern: the "plugin" is the bait; the executable payload is the hook.
- **Tells corroborating:** every README "install" link is a direct zip download; `package.json` repo URL points at a *different* org (`fjzzwxp`); music-themed naming with no musical or mnemonic relationship to the code.
- **Verdict: malicious.** Quarantined copy purged. **Lesson canonized:** in our practice, *any* plugin whose distribution is a zip-of-binaries with a launcher script gets inspected before it gets installed — no exceptions, however pretty the muse.
